# Color Scheme Generator

A responsive color scheme generator built with HTML, CSS, and JavaScript. It uses the Color API to generate color palettes based on a selected seed color and color scheme mode.

# Live Website

[View Project](https://color-scheme-generator-umber.vercel.app/)

## Features

- Choose a seed color using a color picker
- Select from different color scheme modes
- Generate color palettes using the Color API
- Display generated colors and their HEX values
- Click HEX values to copy them to the clipboard
- Toggle between light and dark mode
- Responsive layout for different screen sizes

## Built With

- HTML5
- CSS3
- JavaScript
- The Color API
- Clipboard API
- Lucide Icons

## Preview

The application allows you to select a seed color and a color scheme mode, then generates a matching color palette.

## How It Works

1. Choose a seed color.
2. Select a color scheme mode.
3. Click **Get color scheme**.
4. The app sends the selected options to the Color API.
5. The generated palette is displayed on the page.
6. Click any HEX value to copy it to your clipboard.
7. Use the theme button to switch between light and dark mode.

## API

This project uses [The Color API](https://www.thecolorapi.com/) to generate the color schemes.
